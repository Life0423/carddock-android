# CardDock 主应用三源交付与真机待验

## 交付范围

基线为 main 的 0d1a144，开发分支为 feat/native-three-source-prototype。APK 来自根目录 app，应用 ID 为 com.life0423.carddock.prototype。根目录 app → core 与 RuleSpec v1 保持原有分层。历史 Mika APK、Room 数据和旧真机结果继续由实验工程保存。

| 功能 | 入口 | 本版行为 |
| --- | --- | --- |
| 菜鸟空状态 | 模板 → 菜鸟待取 · 真机 | 试运行或刷新后在 20 秒内手动切到取包裹页，同时匹配「取包裹」和「暂无待取包裹」 |
| 美团历史订单 | 模板 → 美团历史订单 | 输入授权订单号码后开始，25 秒内打开已完成订单并展开「订单信息」，卡片显示状态及下单时间 |
| 京东 A/B 身份 | 模板 → 京东商品 A 或 B | 自动核验公开页主体 SKU、该 SKU 所选规格和名称，普通刷新保留 App 展示价与原核验时间 |
| 京东 App 展示价 | 空间 → 京东卡 → 核验 App 展示价 | 60 秒内打开匹配商品详情，打开分享、停一秒再复制公开链接，等详情恢复后返回卡坞。前后证据及本次链接都匹配才提交 |
| 顺序核验 | 空间 → 顺序核验 | 按空间卡片顺序依次处理。菜鸟、美团逐项确认开始，京东自动核验公开身份，单项失败保留快照并推进 |
| 京东选购 | 选购 | 并列展示 A/B，保存两款快照和一条备注。重开后恢复。重新核验 A/B 只读身份，价格变化需另采新展示价 |
| 模型候选 | 我的 → 模型设置，模板 → 用模型生成菜鸟候选 | 保存 HTTPS 基础地址、模型名和密钥。候选生成、规则预览、真机试运行、确认保存是分开的操作 |

## 使用约定

- 无障碍服务在「我的 → 打开无障碍设置」启用。系统若限制侧载应用授权，由设备持有人按系统提示处理。菜鸟、美团和京东 App 展示价需要该服务，京东公开身份不依赖该服务。
- A 固定 SKU 100305104289，规格 GX 27款/27/黑曜屏/2304分区。B 固定 SKU 100312915069，规格 爆27" 4K 240Hz双模DP2.1/OLED。
- App 展示价记录金额、币种、所选规格、价格标签、可见优惠条件和采集时间。条件不同或未知、最近价格核验失败、缺少一次新价格时，选购页显示无法比较或无法核验。已保存快照仍可查看。
- 模型基础地址填写实际接口前缀，例如 https://example.com/v1，客户端追加 /chat/completions。设置整份用 Android Keystore AES-GCM 加密。模型只收到固定脱敏菜鸟说明，规则严格限定为菜鸟空状态读取，卡片刷新不经过模型。
- 美团本机授权订单号只进应用私有卡片配置。公开交付资料不附订单号码、模型凭据、原始页面或本机私有文件。

## vivo 真机待验

本轮设备暂未交接，以下均待执行。先确认设备已交回，再检查当前前台与无障碍状态。由设备持有人确认 APK 安装和敏感参数输入。根工程 APK 的记录和 Mika 历史记录分别保存。

1. **菜鸟闭环。** 从模板试运行，切到取包裹页，返回卡坞确认并创建，刷新一次，再退出进程重开核对卡片。关闭服务或切到登录页，另测取消，记录旧快照和成功时间。
2. **美团闭环。** 使用本机 O1 订单号码完成试运行、创建及刷新。打开另一订单、折叠订单信息和登录页分别确认旧快照保留。记录本次应用版本与详情容器读取是否匹配。
3. **京东身份。** 分别创建 A、B 并刷新，核对 SKU、规格、名称和身份时间。随后执行一次空间三源顺序核验，确认美团失败时仍能推进并更新京东身份。
4. **京东展示价。** A、B 各核验一次，记录展示价、可见优惠和时间。用 A 详情和 A 分享链接核验 B。分别复测旧剪贴板、浮窗和主动取消。再普通刷新 A/B，核对展示价与价格时间保留。
5. **选购任务。** 保存 A/B 和备注，只重开卡坞进程，核对任务恢复。重核身份后价格变化仍为无法核验；逐款重新采价，再按同 SKU、同规格、同价格条件测试变化或未变化。价格条件变化时记录无法比较。
6. **模型候选。** 在「我的」配置兼容服务并重开，验证设置恢复。实际生成一次，查看规则，完成菜鸟真实试运行后保存。记录服务请求计数，普通卡刷新后核对请求增量为 0。用非法候选作拒绝对照，最后验证清除配置。
7. **重复样本。** 每个核心规则先完成一次正例，再按原计划补足 10 次正常刷新。逐次记录结果、耗时、模型请求增量；错对象及错字段误写成功预期为 0。

## 剩余范围

菜鸟规则替换与回退按计划排在核心真机通过之后。模板导入导出、三方对照、自动导航、取件码和实时配送仍是后续迭代。
