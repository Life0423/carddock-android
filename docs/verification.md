# 验证说明

## 自动化覆盖范围

| 测试层 | 重点 |
| --- | --- |
| 规则验证与引擎 | schema、步骤顺序、来源/目标、缺失/空字段、设备失败、接管、取消 |
| 序列化 | 往返保存、未知步骤、未知 schema |
| 会话与状态 | 首次种子/用户空列表、重启中断、失败保留旧结果、去重、串行运行、取消、关闭草稿、保存门禁、磁盘失败 |

| Compose 与入口 | 页面导航、动作回调、创建保存条件、Android 页面渲染 |

查看具体断言以测试代码为准，不将截图渲染等同于完整实机验收。

## 实机验收清单

自动测试后，正式接入真实设备前仍应在手机上检查：

1. 小屏、较大字体、输入法弹出时，创建页可滚动到保存按钮。
2. 在读取中切换标签页、旋转屏幕，不重复启动任务。
3. 在读取中取消，卡片状态停止；重新刷新可正常执行。
4. 已有成功结果时切换失败场景，内容和成功时间都不被覆盖。
5. 删除卡片或重置后，旧任务不能把内容重新写回来。
6. 强制结束应用后重新打开，未完成任务显示中断，已保存结果仍在。
7. 连续点击刷新或保存，不产生重复任务或重复卡片。

## 本轮交付验证

四栏重构在 JDK 17、SDK 35 环境通过 53 项核心测试、56 项 Android JVM 测试、Debug Lint 及 Debug/Release 构建。旧存档用例覆盖 v1 卡片和 v2 对比组。API 34 模拟器从模板试运行、保存并置顶演示卡，结束进程重开后显示同一结果。预览实验核对了时钟和设置的同会话操作，设备 APK 与本地构建不一致时启动脚本拒绝连接。Release 清单没有预览入口。

`docs/build-verification.md` 保留上一版构建和测试记录。真实来源和模型验收见 README 清单。


## 菜鸟主工程接入

新增合成页面测试覆盖包名与双锚点、登录拒绝、无服务和断线、超时与取消；集成测试使用真实识别器、引擎、控制器完成试运行、保存、失败保留及重启恢复。界面测试覆盖真机模板及无障碍设置入口。合成输入不代表物理手机证据。

实机待验：安装根工程 APK，启用服务，分别检查明确空状态、有包裹、登录页、权限关闭、等待中取消；确认旧结果和成功时间不会被失败更新，并确认返回卡坞能保存试运行结果。上述项目需要连接并登录来源应用的物理设备。
