# 验证说明

## 自动化覆盖范围

| 测试层 | 重点 |
| --- | --- |
| 规则验证与引擎 | schema、步骤顺序、来源/目标、缺失/空字段、设备失败、接管、取消 |
| 序列化 | 往返保存、未知步骤、未知 schema |
| 会话与状态 | 首次种子/用户空列表、重启中断、失败保留旧结果、去重、串行运行、取消、关闭草稿、保存门禁、磁盘失败 |
| Mock 编译器 | 支持的请求、未知或含糊请求 |
| Android 存储 | 首次使用、空集合、数据往返、损坏内容保护 |
| Compose 与入口 | 页面导航、动作回调、创建保存条件、Android 页面渲染 |

查看具体断言以测试代码为准，不将截图渲染等同于完整实机验收。

## 输出位置

## 实机验收清单

自动测试后，正式接入真实设备前仍应在手机上检查：

1. 小屏、较大字体、输入法弹出时，创建页可滚动到保存按钮。
2. 在读取中切换标签页、旋转屏幕，不重复启动任务。
3. 在读取中取消，卡片状态停止；重新刷新可正常执行。
4. 已有成功结果时切换失败场景，内容和成功时间都不被覆盖。
5. 删除卡片或重置后，旧任务不能把内容重新写回来。
6. 强制结束应用后重新打开，未完成任务显示中断，已保存结果仍在。
7. 连续点击刷新或保存，不产生重复任务或重复卡片。

## 本轮交付验证

构建和测试的最终结果记录在交付时生成的 `docs/build-verification.md`。该记录只描述实际执行的检查；GitHub 工作流和物理设备验收需在对应环境执行。
