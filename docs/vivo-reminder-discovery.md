## 使用入口

1. 在「我的」配置模型，连接 Mika 后台助手并启用卡坞页面读取。
2. 在「模板 → 新建模板」输入“查看下一个提醒的名称和时间”，点击「生成候选」。卡坞通过系统日历入口开始只读试查。本机提取脱敏结构，真实模型选择名称、开始时间及通知提前量字段。本机验证字段与日程的对应关系。
3. 卡坞关闭首轮后台屏，从应用入口在新的后台屏重读。两轮字段相同才显示可保存的预览。候选保留来源与字段结构锚点，日程标题、通知时刻及屏幕坐标不进入规则。
4. 点击「保存模板」。在「空间 → ＋ → 我的模板」选择「今日可见提醒」，点击「试运行并预览」和「添加到空间」。以后点卡使用保存的规则。模型请求仅出现在学习字段的分支。
