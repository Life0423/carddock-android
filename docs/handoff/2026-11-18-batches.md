## 批次 2：本地对比组

- `CompareGroup` 只保存组身份、名称与有序卡片 ID；同一卡只能属于一个组。
- 至少两张独立卡才能建组。重命名、成员切换、展开、移出、解散均可达；只剩一张自动解散。
- 组与卡片在同一个原子文件中提交；刷新不会清组；真正删除卡片会同步清引用。移出和解散不删除规则/快照。
- 首页顺序直接使用卡片持久化顺序，组的有序成员放在最早被选位置；解散恢复这些成员，无第二套 feed 数据。
- 建组与重命名成功提交后关闭编辑；失败保留输入，在当前弹层显示错误。

运行路径：空间“新建”→创建对比组→选择两张以上独立卡→保存→点击组→切换/展开/管理成员。退出重开检查组和卡片仍在。

## 迁移与回退

仍使用应用私有目录 `files/cards-v1.json`，文件内容版本从 1 升为 2。读取旧数据时 groups 默认空，originalPrompt 默认空；下一次成功保存原子写入 v2。规则 DSL schemaVersion 保持 1，未混用交接包建议的 `carddock.handoff.rulespec`。

旧 APK 不支持 v2；降级前需要恢复升级前数据备份，直接降级会提示数据无法读取。不要点击重置来尝试迁移。debug 仍为 `com.life0423.carddock.prototype`，不会自动迁移到正式包私有目录。重置仍是明确的破坏性操作，保留确认。

## 构建与安装

```sh
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
export ANDROID_HOME="$HOME/Library/Android/sdk"
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug --console=plain
"$ANDROID_HOME/platform-tools/adb" install -r app/build/outputs/apk/debug/app-debug.apk
"$ANDROID_HOME/platform-tools/adb" shell am start -n com.life0423.carddock.prototype/com.life0423.carddock.MainActivity
```

其他电脑设置各自的 JDK17/SDK 路径；无需改已锁定的 Gradle 与库版本。输出 APK 是调试原型，不是正式签名或商店发布包。
