## 从需求到点卡

在「模板 → 新建模板」输入“查看文件管理的文件页中压缩包的数量”，点击「生成候选」。Mika 通过应用名称解析本机启动入口，打开后台屏。读取器核对同组页签的选中状态，必要时点击用户点名的导航项，随后查找分类及同组数量。模型接收本组节点序号、控件大类、请求标签和数量形态，原文、数值、截图及包名均留在设备上。

学习产生字段锚点，第二次从启动入口打开新后台屏并执行保存用的规则。两次读数相同后才显示可保存的预览。点击「保存模板」，再从「空间 → ＋ → 我的模板」选择模板，试运行后添加到空间。普通点卡重新打开来源、核对页签并读取数值，直接走本机重放分支。

若同一分类旁有多个可分别定位的数量，卡坞可在当前草稿中展示候选供用户点选一次。选择后仍须独立实读。切换需求会清空示范候选。该交互已通过控制器回归，本次真机样本自动选定了唯一字段。
