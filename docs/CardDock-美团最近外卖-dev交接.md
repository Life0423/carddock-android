# CardDock · 美团最近外卖交接（2026-11-19）

本版沿用根工程 app → core。个人模板库、统一账号与广场、内置 Mika 后台读取等自上一版 dev 以来的改动随本次验收源码一并交付。最近外卖目前支持近一个月内，筛选结果能在一屏完整显示且最新下单分钟唯一的已完成外卖。

## 从需求建卡

1. 在已登录美团的测试手机上打开卡坞。「我的」中确认「页面读取服务」和「Mika 后台助手」均为已连接。调试版助手的连接命令为 `./tools/start-mika-helper.ps1 -Serial <设备序列号>`。手机需支持 Android 14 及以上的独立焦点后台屏。
2. 在「模板 → 我的 → 新建模板」输入“查看美团最近一笔外卖”，点「生成候选」，确认展示字段，点「试运行并预览」。看到订单状态、下单时间和美团来源后保存模板。
3. 在「空间 → ＋ → 我的模板」找到刚保存的模板，点「选择」。配置卡片名称，试运行通过后点「添加到空间」。最近外卖自动选择目标，无需订单号或路由。
4. 点空间里的卡面即可后台刷新。用户停留在卡坞，结果和核验时间原位更新。读取中断时，卡面提示失败原因并保留上次成功结果及时间。

## 下一轮开发与验收

- **配送中**。在用户已有配送中订单时，采集同一单的列表状态、详情状态、下单时间与可用身份字段。更新 LatestTakeout 的逐行状态识别及详情读取，让所有状态的订单都参与时间比较，避免跳过较新的配送单。用“最新单配送中、较早单已完成”复测，再验证同一单状态变化后的刷新。
- **跨页查询**。目前可滚动、裁切或无法确认完整性的列表会结束查询。先在真实多屏样本上确认排序、滚动加载过程、相邻页重叠及可辨识的列表终点，再实现限定于筛选结果容器的滚动与去重。用跨页、重复行、加载失败和中途离开卡坞做回归。遍历不完整时保留旧结果与时间。
- **同分钟并列**。当前明确拒绝写入；若要支持，需逐笔进入并列候选详情比较秒级时间、核对身份。依然无法消歧时保留上次快照。
- 代码入口为 `PersonalRuleCompiler.kt`（需求识别）、`LatestTakeout.kt`（筛选、选单与核对）、`MikaBackgroundQuery.kt`（后台屏）、`VisibleDetail.kt`（详情字段）。美团改版后需重新确认筛选选中底色及详情节点，并复测固定历史订单。
