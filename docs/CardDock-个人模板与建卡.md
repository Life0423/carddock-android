# CardDock 个人模板与建卡

「模板」设有「我的」「已下载」「收藏」三栏。在「我的」新建、编辑或删除个人模板。新建时可描述需求生成候选，或在编辑器中选用已有能力。空间「＋」可选择已核验的模板。选择「去创建新模板」并完成保存后，会回到选择器，新模板排在最前。两个入口共用试运行、预览与保存流程。

输入需求即可保存本机草稿并在重开时继续编辑。生成候选后自动填写名称，用户可修改名称、展示字段、顺序与标签。发布要求本次试运行成功。修改查询目标或订单参数会撤销预览和保存资格。编辑可用版时，草稿与发布版分开保存。已建卡持有自己的规则版本，模板删除后仍可独立刷新。

美团固定历史订单试运行可选择已有成功卡片的本机授权目标，同一订单优先复用已有后台路由。也可在「指定历史订单」中填写授权号码和可选路由。最近外卖和配送中订单尚待接入。模板库只保存参数要求，真实参数在确认建卡后随卡保存。模板库与卡片、选购基线各自持久化。Mika 调试连接步骤见 [后台查询说明](CardDock-Mika后台查询.md)。

自定义布局随模板和卡片保存，普通刷新沿用该布局。京东选购比较使用全量身份快照。广场发布确认展示即将公开的自定义字段名，原始需求和本机参数仅供本地使用。旧协议客户端只能看到能够完整呈现的模板。
